# ROD-Manager

An alternative module to the brainrotted modules flying around. ROD-Manager is a KISS helper for your Android modules that consolidates multiple tweaks and kernel-level hiding mechanisms into a single, clean WebUI interface.

## Features

- **BRENE (SuSFS Integration):** Manage kernel-level hiding, including mount hiding, AVC log spoofing, bootloader state spoofing, and custom KSTAT static rules.
- **PlayIntegrityFix (PIF):** Directly sync and inject Play Integrity Fix profiles.
- **OhMyKeymint (OMK):** Automatically fetch and import Keybox.xml files and configure target apps.
- **HMA-OSS:** Automate Zygisk/KSU application hiding configuration and inject custom templates.
- **Zygisk Next:** Automatic setup and configuration for a seamless Zygisk experience.
- **Clean UI:** A modern, distraction-free WebView interface to configure all integrations from a central location.

## Usage
Flash the `ROD-Manager.zip` module in KernelSU. Once installed, tap on the module in the KernelSU app to open the WebUI configuration interface.
